Button

A button does something on this page. Rules are in brief-components/SKILL.md; this page shows the result.

Variants

One primary per view. Default for everything else, ghost for low-emphasis actions, danger only to confirm something destructive.

States

Hover, pressed and focus are forced here with data-state so a static render shows them. Busy keeps the button's width.
